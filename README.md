## Selected Projects

### [Interpretable RL for Inventory Control](https://github.com/cjogilvy/Interpretable_RL_Inventory_Control)

**Reinforcement Learning · Interpretability · ML Engineering · Docker · Hydra · Optuna · Neptune**

Built a configurable stochastic inventory-control environment and DRL experiment pipeline, then distilled the learned policy into interpretable surrogate models.

The project investigates the difference between **imitating an expert policy** and **performing well when the surrogate is actually deployed**. It compares surrogate policies across different environment structures and evaluates them using financial, operational and stability measures rather than imitation error alone.

The workflow uses **Hydra, Optuna, Neptune, Docker, GitHub Actions and Pytest** to support reproducible experiments.

### [Bayesian Machine Learning](https://github.com/cjogilvy/Bayesian_Machine_Learning)

**Bayesian Statistics · Probabilistic Modelling · MCMC · NUTS · NumPyro**

A collection of Bayesian ML work progressing from Bayesian regression and Monte Carlo inference to hierarchical reliability modelling.

The final case study models component degradation from sparse observations using **partial pooling and NUTS**, then estimates future failure risk from the posterior distribution while accounting for uncertainty.

### [Sustain-a-City](https://github.com/cjogilvy/Sustain-A-City)

**Software Engineering · Godot · GDScript · Team Development**

A seven-person software-engineering project developing a city-building simulation with interacting pollution, income, electricity and happiness systems.

The team worked through weekly sprints using **user stories, acceptance criteria, Jira/Kanban, pair programming, mob programming, pull requests, peer review and user-story testing**. My contributions included stateful simulation mechanics, UI behaviour, debugging and project coordination, and I served as **Product Owner, Scrum Master and documentation lead** at different stages.
